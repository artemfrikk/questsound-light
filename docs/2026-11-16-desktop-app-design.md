# QuestSound Light как программа — дизайн

## Зачем
Мост сейчас — консольная программа: `start.cmd`, чёрное окно, код в терминале. Подключать свет должен
и человек далёкий от техники: скачал файл, дважды щёлкнул, увидел понятное окно в стиле сайта.

## Цели
- Один файл на систему, без установщика: Windows `QuestSound Light.exe` (portable), macOS
  `QuestSound Light.app` в zip (arm64 и x64), Linux `QuestSound-Light.AppImage`.
- Никакого терминала. Окно в дизайне сайта: состояние связи, код привязки крупно с кнопкой
  «Скопировать», состояние подключений (модуль → сколько ламп / ошибка), «Отвязать»,
  «Запускать вместе с компьютером», свёрнутый «Журнал».
- Крестик прячет окно в трей, свет продолжает работать. Меню значка: «Открыть», «Выйти».
  Первый раз программа говорит, что ушла в трей.
- Raspberry Pi и опытные пользователи: консольная версия остаётся (архивы с Node внутри, как в 0.1.3).

## Не цели (сейчас)
- Настройка подключений в окне — они настраиваются на сайте. Следующий этап: карта ламп и свет сцен
  в программе (окно уже строится из отдельных блоков, чтобы их добавить).
- Подпись кода (Windows, Apple) и автообновление.

## Анти-цели
- Окно грузит что-то из интернета. Интерфейс целиком внутри программы, contextIsolation, без nodeIntegration,
  в окно — только узкий набор действий через preload.
- Ядро моста получает зависимости. Electron и сборщик — только для обёртки.

## Подходы
1. **Electron (выбран).** Одинаковое окно на всех системах, трей, portable exe. Минус: ~90 МБ,
   зависимость Electron.
2. Tauri: меньше файл, но Rust + Node в сборке и разный вид окна на системах.
3. Программа без терминала + вкладка браузера: не «программа», нет трея.
Пользователь выбрал Electron и потребовал: без установщика, файл просто открывается.

## Как устроено
- `lib/bridge.mjs` — ядро, общее для консоли и окна: `startBridge({ server, repair, log })` → объект
  с `status()` (версия, сервер, online, code, linked, modules, lampCount), событием изменения,
  `unpair()`, `stop()`. Логика кода привязки и отвязки переезжает сюда из `questsound-light.mjs`.
- `questsound-light.mjs` — консоль поверх ядра (поведение прежнее).
- `app/main.mjs` — Electron: одно окно (single instance), трей, автозапуск (Windows/macOS через
  `setLoginItemSettings`, Linux AppImage через `~/.config/autostart`), закрытие в трей.
- `app/preload.cjs` — `window.qsl`: `onStatus`, `copyCode`, `unpair`, `getAutostart/setAutostart`, `openSite`, `quit`.
- `app/ui/` — HTML/CSS/JS окна, цвета и шрифт (Manrope, вложен) как на сайте.
- Сборка: GitHub Actions, по машине на систему, electron-builder (`portable`, `zip`, `AppImage`), плюс
  прежние консольные архивы; всё в один релиз с `SHA256SUMS`.

## Решения за исполнителем
Размер окна (~460×640), тексты, иконка трея (знак сайта), порядок блоков.

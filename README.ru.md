# QuestSound Light

[English](README.md)

Мост между [QuestSound](https://questsound.ru) и вашим умным светом. Сцена в таверне становится тёплой, в бою свет красный, в ночном лесу тёмно-синий. Сайт отдаёт общую команду «эта лампа: цвет, яркость, переход», а мост переводит её на язык ваших ламп.

> **Бета-версия.** Возможны задержки, ошибки и неожиданное поведение ламп.

## Что поддерживается

| Подключение | Лампы | Эффекты |
|---|---|---|
| **Home Assistant** | всё, что подключено к HA: Zigbee, Wi-Fi, Hue, IKEA и другие | да |
| **Yeelight** | лампы и ленты Yeelight по локальной сети | да |
| **Яндекс** | лампы из «Дома с Алисой» через официальный API | нет (через облако, около секунды задержки) |
| **MQTT** | Zigbee2MQTT и всё, что слушает MQTT | да |
| **WLED** | ленты и лампы на прошивке WLED | да |
| **Веб-запрос** | Node-RED и всё, что принимает HTTP | нет |

## Установка

Нужен компьютер или Raspberry Pi в той же сети, что и лампы. Он должен быть включён во время игры.

### Windows

1. Скачайте `questsound-light-win-x64.zip` со страницы [Releases](../../releases/latest) и распакуйте.
2. Запустите `start.cmd`. Node.js уже внутри архива, ставить ничего не нужно.
3. Windows может предупредить, что программа не подписана. Нажмите «Подробнее» → «Выполнить в любом случае». Исходный код открыт и лежит в этом репозитории, а контрольные суммы архивов есть в `SHA256SUMS`.

### Raspberry Pi (64-битная ОС) и Linux

```bash
tar xzf questsound-light-linux-arm64.tar.gz
cd questsound-light
./node/bin/node questsound-light.mjs
```

Чтобы мост запускался сам вместе с Pi, используйте файл `questsound-light.service` (инструкция внутри него).

### Если Node.js 18+ уже установлен

```bash
git clone https://github.com/artemfrikk/questsound-light
cd questsound-light
node questsound-light.mjs
```

## Привязка

1. Мост при первом запуске показывает код из 6 символов.
2. На questsound.ru откройте вкладку **«Освещение»** и введите код.
3. Готово. Дальше мост подключается сам при каждом запуске. Код живёт 10 минут, мост обновляет его, пока сайт не подключится.

Чтобы привязать заново: `node questsound-light.mjs --pair`.

## Настройка подключений

Подключения настраиваются на сайте во вкладке «Освещение» → «Подключения». Настройки сохраняются в мосте (файл `~/.questsound-light.json`), а на сайте токены не видны.

### Home Assistant

- **Адрес:** например, `http://homeassistant.local:8123` или `http://192.168.1.10:8123`.
- **Токен:** в Home Assistant откройте свой профиль → «Безопасность» → «Долгосрочные токены доступа» → «Создать токен».

### Yeelight

В приложении Yeelight откройте каждую лампу → настройки → включите **«Управление по локальной сети» (LAN Control)**. Мост найдёт лампы сам. Если не нашёл, впишите их IP-адреса.

### Яндекс

1. Зайдите на [oauth.yandex.ru](https://oauth.yandex.ru) → «Создать приложение».
2. Платформа «Веб-сервисы», Redirect URI: `https://oauth.yandex.ru/verification_code`.
3. Доступы: «Умный дом» → `iot:view` и `iot:control`.
4. Скопируйте ClientID и откройте в браузере `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`.
5. Разрешите доступ. Яндекс покажет токен, вставьте его на сайте.

### MQTT

- **Адрес брокера и порт** (обычно 1883), логин и пароль, если они есть.
- **Лампы:** по одной в строке, `название=тема`, например `Потолок=zigbee2mqtt/Потолок`. Мост отправляет в `тема/set` сообщение в формате Zigbee2MQTT.

### WLED

Адреса устройств через запятую: `192.168.1.50, wled-strip.local`.

### Веб-запрос

Метод, адрес и тело запроса с подстановками `{{lamp}} {{r}} {{g}} {{b}} {{hex}} {{bri}}` (0–100) `{{bri255}} {{on}} {{fade}}` (секунды). Названия «ламп» задаёте сами: для каждой отправляется отдельный запрос.

## Безопасность

Что мост делает и чего не делает, описано в [SECURITY.md](SECURITY.md). Коротко:
- мост обращается только к questsound.ru и к адресам, которые вы указали;
- токены хранятся только в файле на вашем компьютере;
- у моста нет зависимостей, телеметрии и автообновления.

## Свой модуль

Модуль — это файл в `modules/`, который экспортирует объект:

```js
export default {
  id: 'mybrand', name: 'My brand', rate: 5,             // команд в секунду на лампу
  settings: [{ key: 'host', label: 'Адрес' }, { key: 'token', label: 'Токен', secret: true }],
  async start(settings) {},                               // подключиться, бросить ошибку, если не вышло
  async discover() { return [{ id, name, caps: { color: true, fast: true } }]; },
  async set(id, target) {},                               // target: { color: '#rrggbb', bri: 0..1, fade: сек } или 'off'
  async stop() {},
};
```

Добавьте его в `modules/index.mjs`. Для облачных API с общим лимитом вместо `set` можно определить `setMany({ id: target })`.
